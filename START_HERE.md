# Start Here — Fact Box Consult V1

This is a fresh-build starter pack containing the reconciled project contract and the supplied visual references. It is not a running application.

## Before asking a coding agent to implement anything
1. Open `README_PROJECT_DOCS.md` and follow its reading order.
2. Read `AGENTS.md` and `CLAUDE.md`.
3. Inspect `design_reference/` and `stitch_fact_box_cinematic_showcase/` for the supplied Stitch HTML, screenshots, and `DESIGN.md`.
4. Start with Roadmap Stage 0: inspect the target workspace, confirm Python/PostgreSQL setup, and document the environment. Do not start generating all features in one pass.
5. Keep this package's requirements intact unless the user explicitly approves a documented change.

## Important
- No Flask application code has been generated yet.
- No hosting, database, domain, Cloudinary or email service has been provisioned.
- Never put real credentials into this package or commit `.env`.
- The original Stitch screens include concepts excluded from V1; the reconciled PRD and roadmap determine what ships.
